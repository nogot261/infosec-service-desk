# Публикация учебной версии на Render

Для веб-приложения используется **Render Web Service**, а не GitHub Pages.
Docker устанавливать не нужно: в `render.yaml` используется обычный Python.
`Dockerfile` приложен только как альтернативный способ запуска.

## Развёртывание по шагам

1. В Render открыть **New > Blueprint**.
2. Подключить GitHub и выбрать `nogot261/infosec-service-desk`.
3. Выбрать ветку `flask-render-20261124` и подтвердить использование `render.yaml`.
4. Дождаться успешной сборки и запуска сервиса. Render сам установит
   зависимости через `requirements-deploy.txt` и запустит `gunicorn wsgi:app`.
5. В настройках окружения Render проверить, что автоматически созданы
   `INFOSEC_SECRET_KEY` и `INFOSEC_DEMO_PASSWORD`.
6. Скопировать `INFOSEC_DEMO_PASSWORD` из Environment в Render.
   Для трёх тестовых пользователей `admin`, `operator`, `employee` пароль
   на публичном сервере **одинаковый**, но не включён в репозиторий.
7. Открыть адрес сервиса, затем `/health`, `/public/overview`, `/login`.
   Войти под каждым пользователем, создать заявку, сменить её статус,
   проверить CSV, XLSX и доступ к чужим заявкам.

## Как сохраняются данные

На бесплатном тарифе файловая система Render временная. `wsgi.py` копирует
учебную базу из `instance/demo.sqlite3` в `/tmp` при создании нового экземпляра.
После следующего развёртывания/перезапуска изменения пользователей могут
пропасть. Для дипломной демонстрации это допустимо, поскольку база учебная.
Для настоящих заявок нужны постоянная СУБД и отдельная настройка доступа.

## Защита данных

Пароли из локального `README.md` **не используются на Render**:
перед запуском `wsgi.py` задаёт новые хэши трём учебным пользователям.
Настоящие сведения организаций и действующие секреты сюда не загружать.
Секреты Render не сохранять в GitHub и не вставлять в отчёт.

## Если не работает

Если в логах `INFOSEC_SECRET_KEY` или `INFOSEC_DEMO_PASSWORD must be set`,
открыть Environment и добавить соответствующую переменную со случайным
значением длиной от 32 или 14 символов. Запустить Manual Deploy.
Если ошибка импорта `infosec_desk`, проверить установку `requirements-deploy.txt`.
Если страница не открывается, проверить наличие успешного `healthCheckPath: /health`.

Адрес сайта, дата и пройденные браузерные проверки включаются в отчёт только
**после фактического развёртывания**.
