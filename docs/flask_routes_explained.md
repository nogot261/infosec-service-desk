# Как устроены адреса страниц

Обработчики в `src/infosec_desk/web.py` сгруппированы по назначению. Открытые материалы находятся по `/public/<slug>`, а обратная связь - по `/feedback`.

Заявитель после входа видит `/`, `/tickets`, `/tickets/new`, `/tickets/<id>`, `/profile`, `/my-activity`, `/notifications` и `/my-help`. В обработчиках форм данные проверяются до записи, поэтому сообщение с пустым обязательным полем не должно создавать заявку.

Специалист работает с назначенными или доступными ему карточками, комментариями и изменением статусов. Экспорт CSV и XLSX находится на `/export.csv` и `/export.xlsx`; параметр `status` должен ограничивать данные в выгрузке, а не только таблицу просмотра.

Администратор получает `/users`, `/audit`, `/admin/services`, `/admin/feedback`, `/admin/settings`, `/admin/data-exchange`, `/admin/analytics`. Защита маршрутов проверяется при прямом открытии адреса. Таблица фактических прав: `docs/route_matrix.md`.
