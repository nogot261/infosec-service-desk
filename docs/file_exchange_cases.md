# Примеры файлового обмена

JSON служит для переноса справочника средств защиты между экземплярами учебного приложения. Экспорт включает инвентарный номер, название, размещение и класс защиты. Импорт проверяет формат и не должен бесконтрольно дублировать существующие записи. Действия доступны администратору через `/admin/data-exchange`.

CSV и XLSX служат для представления реестра заявок. Без фильтра в контрольной базе ожидается 501 строка данных, при фильтре `status=closed` - 251. Заголовок в CSV отделяется от строк данных; в XLSX он занимает первую строку.

Проверять следует два разных результата: готовые файлы из `samples` и непосредственную выгрузку из работающего приложения. Совпадение числа строк в готовом образце не подтверждает, что веб-маршрут исправлен.

Тестовые файлы содержат только вымышленные данные, реальные сведения организации при демонстрации не используются.
