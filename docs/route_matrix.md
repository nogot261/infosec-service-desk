# Адреса страниц и права доступа

| Адрес | Страница | Доступ |
|---|---|---|
| `/public/overview` | О службе | Все |
| `/public/services` | Услуги | Все |
| `/public/submit` | Как подать заявку | Все |
| `/public/categories` | Категории | Все |
| `/public/priorities` | Приоритеты | Все |
| `/public/status` | Статусы | Все |
| `/public/tracking` | Отслеживание | Все |
| `/public/faq` | Ответы на вопросы | Все |
| `/public/security` | Конфиденциальность | Все |
| `/public/help` | Помощь | Все |
| `/public/contacts` | Контакты | Все |
| `/public/rules` | Правила | Все |
| `/feedback` | Обратная связь | Все |
| `/login` | Вход | Все |
| `/` | Панель управления | Три роли |
| `/tickets` | Реестр заявок | Три роли (заявитель - свои) |
| `/tickets/new` | Создание заявки | Три роли |
| `/tickets/<id>` | Карточка заявки | Три роли (права на заявку) |
| `/assets` | Средства защиты | Три роли |
| `/profile` | Личный кабинет | Три роли |
| `/my-activity` | Моя активность | Три роли |
| `/notifications` | Уведомления | Три роли |
| `/my-help` | Помощь | Три роли |
| `/users` | Пользователи | Администратор |
| `/audit` | Журнал | Администратор |
| `/admin/services` | Каталог услуг | Администратор |
| `/admin/feedback` | Сообщения посетителей | Администратор |
| `/admin/settings` | Настройки | Администратор |
| `/admin/analytics` | Статистика | Администратор |
| `/admin/data-exchange` | Файловый обмен СЗИ | Администратор |

Гость видит только справочные страницы и форму обратной связи. Специалист видит все заявки, заявитель - только созданные им. Право доступа проверяется на сервере, а не только скрытием меню.
