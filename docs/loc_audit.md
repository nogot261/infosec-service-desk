# Проверка объёма собственных исходных файлов

Расчёт выполнен 23.11.2026 на версии 2.0.0.

- 2 072 непустые строки исходного Python-кода, HTML-шаблонов, CSS и SQL без тестов.
- 646 непустых строк собственных тестов.
- 98 непустых строк собственных средств проверки и подсчёта.
- Всего 2 816 непустых строк собственного кода, тестов и вспомогательных средств.

Не включаются сторонние библиотеки, документация, HTML-макеты, пробельные строки и строки обычных комментариев. Это воспроизводимый подсчёт строк файлов, но он не тождествен строгому определению логических строк кода (LLOC). Для окончательной приёмки преподаватель может уточнить способ подсчёта.

Запуск подсчёта: `python tools/count_loc.py`.
