# Эксплуатация учебной версии

Перед исправлениями сохранять копию SQLite. Новую версию не тестировать на рабочей БД без резервной копии. После изменения схемы проверить повторный запуск, сохранность заявок и журнал.

Порядок при обнаружении сбоя: воспроизвести на учебном наборе, зафиксировать входные данные, проверить логи, исправить код, добавить тест, запустить весь набор, обновить реестр дефектов и инструкцию.

Версии зависимостей должны быть повторяемыми; не заменять точные версии диапазонами без отдельной проверки совместимости.
