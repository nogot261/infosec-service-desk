# Форма обратной связи

Без входа открыть `/feedback`, отправить сообщение с корректными именем, адресом и текстом. Убедиться в сообщении об успешной регистрации. Войти администратором, открыть `/admin/feedback`, найти обращение и отметить его как обработанное.

Негативные случаи: пустые обязательные поля, слишком длинный текст, некорректный адрес, отсутствие CSRF-токена. Для каждого отказа убедиться, что лишние записи не появились в базе.

Форма обратной связи не должна показывать список заявок, внутренний журнал, сотрудников или персональные сведения без авторизации.
