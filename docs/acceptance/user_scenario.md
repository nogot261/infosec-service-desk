# Сквозной сценарий приёмки

1. Заявитель входит и создаёт обращение об ошибке доступа к защищённому ресурсу. Записывает номер.
2. Специалист находит обращение, назначает себя исполнителем и переводит в статус «В работе».
3. Специалист оставляет комментарий с диагностикой и меняет статус на «Решена».
4. После проверки обращение закрывают. В карточке должны остаться все переходы и комментарии.
5. Администратор открывает журнал и убеждается, что зафиксированы действия, которые предусмотрены аудитом.

Скриншоты следует делать из одной и той же работающей версии. Фиксировать номер заявки, дату, роль, адрес страницы, результат. Не использовать реальные ФИО и секретные сведения.
