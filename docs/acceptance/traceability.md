# Как проверять требования без доверия к описанию

Выполнение проверяется одновременно по коду, работающей странице и документу. Таблица адресов: `docs/route_matrix.md`. Полный перечень: `docs/requirements_21.md`. План испытаний: `docs/test_plan.md`.

Для маршрута важно проверить два случая: доступ разрешён нужной роли и отказ постороннему пользователю. Для таблиц SQLite следует проверить реальные записи, а не просто наличие SQL-файла. Для экспорта считать строки данных без заголовка и отдельно проверять фильтрацию.

Для макетов файл HTML показывает проектное решение, но не заменяет снимок работающего интерфейса. Снимки готовой версии и сведения о браузерах добавляются после развёртывания.
