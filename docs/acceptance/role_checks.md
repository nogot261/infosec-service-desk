# Разграничение прав

Три роли: заявитель (requester), специалист (operator), администратор (admin). До начала проверки создать отдельные тестовые заявки от двух разных заявителей. Проверять не только отсутствие пунктов меню, но и прямое открытие адреса.

Заявитель может видеть собственные карточки и оставлять комментарии. Специалист может работать с доступными заявками и менять их статус. Администратор может управлять справочниками, пользователями, сообщениями и настройками. Попытки заявителя открыть `/users`, `/audit`, `/admin/settings` должны получать отказ.

Нельзя считать проверку успешной, если чужая карточка скрыта в списке, но открывается по прямому URL. Для файлов-вложений должны действовать те же ограничения, что и для карточки заявки.
