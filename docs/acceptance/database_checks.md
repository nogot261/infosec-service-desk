# Проверка учебной базы и миграции

Используется SQLite. Проверить число предметных таблиц без системной `sqlite_sequence`, наличие внешних ключей и связи заявки с заявителем, исполнителем, СЗИ, комментариями, вложениями, уведомлениями и историей статусов.

Отдельно проверить повторный вызов `initialize`: таблицы не должны дублироваться, существующие обращения не должны теряться. Старую учебную базу перед миграцией следует копировать, потому что перенесённая база может не иметь новых полей.

Файл `instance/demo.sqlite3` содержит только вымышленные сведения и не предназначен для хранения данных организации.
