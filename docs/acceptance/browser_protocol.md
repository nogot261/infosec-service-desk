# Проверка интерфейса в браузерах

Проверить Chrome, Firefox, Яндекс Браузер и Microsoft Edge на одной и той же версии и одной базе. До проведения испытания статус каждого пункта: «не проверено».

Для каждого браузера открыть без входа главную справочную страницу, десять публичных разделов и форму обратной связи; отправить обращение с валидными данными. Затем проверить вход под каждой ролью, видимость меню и запрет доступа к чужой заявке. После этого создать заявку, назначить исполнителя, сменить статусы и проверить историю.

В протокол записывать имя браузера, версию, ОС, конкретный адрес страницы, фактическое поведение, снимок при дефекте, дату проверки. Формулировка «работает во всех браузерах» допустима только после ручного прохождения всех четырёх испытаний.
