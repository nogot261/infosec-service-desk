# Ограничения публичного демонстрационного сервера

Учебная база содержит заранее известные логины и пароли, поэтому её нельзя использовать как настоящий сервис предприятия. На публичном сайте не размещать реальные обращения, ФИО сотрудников, файлы с секретами и персональные данные.

Для сеансов требуется длинный случайный `INFOSEC_SECRET_KEY`, безопасные cookie поверх HTTPS. Для платного развёртывания с постоянным хранением нужен отдельный защищённый том либо внешний сервер БД, резервные копии и контроль доступа.

На бесплатном Render данные SQLite в рабочей директории могут исчезнуть после перезапуска, поэтому сценарий из `wsgi.py` поднимает отдельную копию учебной базы. Это пригодно только для демонстрации, а не для постоянной эксплуатации.
