# Какие скриншоты нужны для отчёта

Фотографировать/снимать итоговую живую версию, а не статические HTML-макеты. Подготовить: вход, открытые страницы, панель управления каждой роли, реестр, создание обращения, назначение исполнителя, изменение статуса, комментарии, история, закрытие, СЗИ, каталог услуг, обратная связь, экспорт и административный журнал.

На каждом снимке должны читаться важные подписи; окно браузера не должно перекрывать область формы. Скриншот подписать в отчёте, указать номер рисунка и сделать ссылку на него в тексте. Для примера использовать одну и ту же заявку.

Снимки с макетов допускаются только как макеты, но не как подтверждение работы программы.
