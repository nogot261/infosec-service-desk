# Проверка запуска с чистого компьютера

1. Склонировать репозиторий в пустую папку, убедиться, что Python поддерживается и присутствует `requirements.txt`.
2. Установить зависимости в виртуальное окружение.
3. Подготовить SQLite при помощи `python run.py init-db`. В отдельной учебной базе запустить `seed-demo` один раз.
4. Запустить `python run.py serve`, открыть адрес приложения и войти под каждым учебным пользователем.
5. Открыть публичную страницу, создать и закрыть заявку, выгрузить CSV и XLSX.
6. Повторить после перезапуска и убедиться, что локальная база не пропала.

Записать ОС, версию Python, дату и любые отклонения. Это инструкция для проверки, а не свидетельство выполненного испытания.
