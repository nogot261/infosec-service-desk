# Учёт обнаруженных ошибок

Каждую ошибку регистрировать по воспроизводимому сценарию, отдельно от пожеланий по оформлению. Обязательные поля: идентификатор, дата, среда, предусловие, действия, ожидание, фактический результат, серьёзность, приоритет, исправление, повторная проверка.

Пример подтверждённого дефекта предыдущей версии: выгрузка 501 заявки возвращала 500 строк данных. Причина: лимит выборки из реестра. Во Flask-версии код экспорта вызывает выборку без лимита. Контрольные CSV/XLSX на 501 и 251 запись вложены в `samples`. Повторную проверку из браузера фиксировать только после её проведения.

| Код | Дефект | Серьёзность | Приоритет | Исправление | Повторная проверка |
|---|---|---|---|---|---|
| DEF-01 | Экспорт ограничен 500 строками | Высокая | Высокий | Убрано ограничение экспорта | По сценариям из `docs/test_plan.md`; запуск Flask требует подтверждения |
