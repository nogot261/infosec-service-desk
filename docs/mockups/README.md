# Макеты страниц

В этой папке сохранены 30 статических HTML-макетов. Они построены из тех же Jinja2-шаблонов, которые использует веб-приложение, с учебными данными из `instance/demo.sqlite3`.

Откройте нужный файл `.html` в браузере после распаковки архива. Для удобства файлы названы по назначению: `public_...` - публичные страницы, `admin_...` - разделы администратора. Формы в макетах не отправляют данные, а относительные ссылки в навигации предназначены для работающего приложения.

**Макеты не являются подтверждением проверки действующего веб-сервера в Chrome, Firefox, Яндекс Браузере и Edge.** Такая проверка выполняется отдельно после запуска Flask.
