# Файловый обмен и сопровождение

## Назначение

Модуль `exchange.py` обеспечивает перенос справочника средств защиты в формате JSON UTF-8.
Это самостоятельный файловый интерфейс. Подключение к реальной корпоративной базе данных,
LDAP, Active Directory, почте или оборудованию защиты не выполнялось.

## Формат

Корневой объект JSON содержит `format: "infosec-assets-v1"` и массив `items`.
Поля элемента: `inventory_no`, `name`, `location`, `protection_class`, `description`.
Все значения строковые, инвентарный номер обязателен и однозначно определяет объект.

Пример:

```json
{"format":"infosec-assets-v1","items":[{"inventory_no":"FW-101","name":"Межсетевой экран","location":"Серверная","protection_class":"Сетевой","description":"Лабораторный образец"}]}
```

## Команды

```bash
python run.py export-assets --file assets.json
python run.py import-assets --file assets.json
python run.py backup-db --file backup.sqlite3
python run.py check-update --file release.json
```

Один и тот же синтаксис действует на Windows и Ubuntu. Импорт валидирует структуру
всего файла до записи, ограничен 1000 объектами и 2 МиБ и работает в транзакции.
Существующие инвентарные номера пропускаются без перезаписи. Результат импорта
фиксируется в общем журнале операций; в нем не указывается оператор, так как команда
выполняется локальным пользователем ОС, а не в веб-сеансе.

Команда `backup-db` использует SQLite Backup API и не перезаписывает уже имеющийся файл.
Проверка `check-update` читает только метаданные:

```json
{"format":"infosec-release-v1","version":"1.1.0","sha256":"ffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffff"}
```

Она не загружает и не устанавливает программу. Полный автоматизированный цикл обновления
потребовал бы доверенного источника релизов, проверки подписи, миграций и тестов отката.

## Ограничения

Работать с файлами импорта и делать резервные копии может любой человек,
имеющий доступ к локальному терминалу и данным проекта. Этот механизм не должен
быть доступен обычному пользователю веб-приложения. Модули не подразумевают
интеграцию с университетом без предоставленных API, правил авторизации и согласования.
