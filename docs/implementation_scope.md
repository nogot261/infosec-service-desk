# Назначение и границы работы

Работа выполняется по теме преддипломной практики «Разработка автоматизированной системы учета заявок на обслуживание систем защиты информации».

Период практики: **09.11.2026 - 06.12.2026**.

В комплекте представлены исходный код информационной системы, SQL-схема, тесты, отчет и техническое задание.

Приложение использует локальную базу SQLite. Реализованы веб-интерфейс, разграничение доступа, история обработки заявок, даты решения и закрытия, управление учетными записями и справочником СЗИ. Передача данных во внешние информационные системы ограничена файловыми форматами CSV и JSON.
