# Руководство пользователя

## Вход и выход

Откройте `http://127.0.0.1:8000`, введите логин и пароль. Для выхода нажмите «Выйти из системы» в левой панели.

## Регистрация заявки

1. Откройте «Заявки» и выберите «Новая заявка».
2. Заполните тему и подробное описание проблемы.
3. Укажите категорию и приоритет.
4. При необходимости выберите средство защиты информации.
5. Нажмите «Зарегистрировать заявку». Откроется ее карточка.

## Обработка заявки

Специалист выбирает заявку из списка, назначает исполнителя и меняет статус на «В работе». После устранения неисправности переводит заявку в «Решена», затем в «Закрыта». При необходимости допустим возврат решенной заявки в работу.

## Комментарии

В карточке заявки размещены комментарии и история. Заявитель может оставлять комментарии только к собственным обращениям. Специалист и администратор работают со всеми обращениями.

## Справочники и экспорт

Администратор добавляет пользователей на странице «Пользователи», средства защиты на странице «Средства защиты». Специалист и администратор могут сохранить реестр заявок в файле CSV со страницы «Заявки».
