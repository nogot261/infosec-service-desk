# InfoSec Service Desk

Веб-система регистрации и обработки заявок на обслуживание систем защиты информации.

## Возможности

- Регистрация и поиск заявок, приоритеты и категории
- Назначение исполнителей и контроль жизненного цикла заявки
- Комментарии и история действий
- Учет средств защиты информации
- Роли: заявитель, специалист, администратор
- Экспорт реестра заявок в CSV
- Хранение данных в SQLite без отдельного сервера БД

## Требования

Python 3.10 или новее. Windows 10/11 или Ubuntu 22.04/24.04 (и другие системы с Python 3.10+).

## Единый запуск на Windows и Ubuntu

Перейдите в папку проекта, затем выполните **одну и ту же команду**:

```bash
python run.py
```

При первом запуске программа установит необходимые пакеты в `.venv`, если они
еще отсутствуют, создаст базу SQLite и выведет в терминал случайный пароль
первоначального администратора. Сохраните его: пароль показывается только один раз.

Откройте в браузере `http://127.0.0.1:8000` и войдите с логином `admin`.
Повторный запуск: та же команда `python run.py`.

Требуется установленный Python 3.10+ с поддержкой `venv` и команда `python`
в PATH. В Ubuntu, где установлен только `python3`, однократно настройте алиас
`python` на Python 3 (например, пакет `python-is-python3`). Для первой установки
зависимостей требуется интернет, далее обычный запуск автономный.

## Демонстрационное наполнение

Для отдельной пустой базы можно добавить тестовые записи командой `python run.py seed-demo`. При обычном запуске тестовые учетные записи не создаются:

| Логин | Пароль | Роль |
|---|---|---|
| admin | DemoPass123! | Администратор |
| operator | DemoPass123! | Специалист |
| employee | DemoPass123! | Заявитель |

Демонстрационные учетные записи не создаются автоматически. Не используйте их на сервере с доступом из сети.

## Команды обслуживания

| Команда | Назначение |
|---|---|
| `python run.py` | Создать учетную запись при первом старте и запустить сервер |
| `python run.py init-db` | Создать пустую базу |
| `python run.py create-admin` | Добавить администратора вручную |
| `python run.py seed-demo` | Добавить тестовые записи в пустую базу |

В файле `.env.example` приведены переменные окружения для настройки секретов,
порта и хранения базы. Для сетевой эксплуатации нужны HTTPS, резервное
копирование и постоянный `INFOSEC_SECRET_KEY`.

## Границы реализации

Приложение представляет локальный прототип с реальным сохранением заявок. Не предусматривает подключения к сетевому оборудованию, Active Directory, антивирусным консолям и другим внешним системам. Установка на сервер, резервное копирование, TLS, мониторинг и дополнительные меры защиты должны выполняться администратором организации до ввода в эксплуатацию.
