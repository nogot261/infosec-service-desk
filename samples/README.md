# Образцы выгрузки учебного реестра

Файлы созданы напрямую из предметной функции чтения SQLite для сверки количества строк. Они не являются протоколом HTTP-проверки веб-интерфейса.

- `registry_all_501.csv` и `.xlsx`: 501 запись плюс строка заголовков.
- `registry_closed_251.csv` и `.xlsx`: 251 запись со статусом «Закрыта» плюс строка заголовков.

После установки Flask сравните результаты скачивания из интерфейса с этими образцами.
